### Currency Converter

A responsive and user-friendly **Currency Converter web application** that allows users to quickly convert amounts between different international currencies. The application provides a clean interface, supports multiple currencies, and dynamically calculates conversion values using real-time exchange rates.

**Key Features:**

* 💱 Convert between multiple international currencies
* 🔄 Instant currency conversion with dynamic rate updates
* 🌍 Support for various global currencies
* 📱 Fully responsive design for desktop and mobile devices
* ⚡ Fast and simple user experience
* 🎯 Clean and intuitive interface

**Tech Stack:** React JS
